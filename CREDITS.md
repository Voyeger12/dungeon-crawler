# Credits

Rune Deep verwendet ausschließlich eigens für dieses Projekt erstellten Code und prozedural erzeugte Inhalte.

- Figuren, Umgebung, Symbole, Partikel und Beleuchtung werden mit der Canvas-2D-API gezeichnet.
- Musik und Soundeffekte werden zur Laufzeit mit der Web Audio API synthetisiert.
- Menüs und HUD verwenden lokale Systemschriften und eigenes CSS.

Es werden keine externen Bild-, Audio-, Font- oder sonstigen Medienassets ausgeliefert. Entsprechend sind keine Drittanbieter-Assetlizenzen erforderlich.
